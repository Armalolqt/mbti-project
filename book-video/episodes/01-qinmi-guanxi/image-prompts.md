# 第01期 生图提示词

只有 kind 为 image 或 mix 的场景需要生图；ui 场景全部用代码画。生成后放到 `assets/scenes/<场景ID>.png`。

## 统一风格前缀（每条都要带上）

```
16-bit pixel art, cozy cinematic lighting, warm desk-lamp amber (#E8B04A) against deep navy night (#1B2340), soft rose accent (#E58FA0) for emotional moments, chunky readable pixels, subtle dithering, no text, no logos, 16:9, consistent chibi-proportioned characters: Character A short black hair, mustard scarf; Character B shoulder-length brown hair, navy coat
```
